# Multimodal Explainable AI for Clinical Decision Support Systems

## AIIMS New Delhi Case Study

This repository contains a research case study on:

- Explainable AI (XAI)
- Multimodal Deep Learning
- Clinical Decision Support Systems (CDSS)
- AI in Healthcare
- Personalized Medicine

## Research Focus

The study explores the development of a Multimodal Explainable AI framework for clinical decision support at AIIMS New Delhi.

### Key Areas
- Sepsis Prediction
- ICU Mortality Prediction
- Diabetic Retinopathy Detection
- Medication Error Detection
- Radiology Report Generation

## Technologies & Concepts

- SHAP
- Grad-CAM
- LIME
- Integrated Gradients
- Multimodal Fusion
- Clinical AI
- Federated Learning
